## 制限事項

- ローカルの単一マシンでの利用を前提にしています。1 つのデータフォルダーに対して動かせる YAMLite のプロセスは 1 つです。
- 想定するのは、テーブルあたり数百から数千レコードです。同期のたびにテーブル全体を走査します。
- SQLite の外部キー制約には対応していません([参照](configuration.md#参照)は検証しますが、強制はしません)。読み取るのは YAML だけです。`.md` と `.mdx` は YAML フロントマターを読み取りますが、TOML や JSON のフロントマターとその他の形式は読み取りません。
- テーブルを分割できるのは、1 つのカラムだけです。
- ファイルを書き換えるとき、行末コメントの前の空白は 1 つにそろえられます(`a: 1  # note` → `a: 1 # note`)。
